v2.0.2 Update

Smart Tab Management

A new memory-pressure tier system, per-domain timeout overrides, and a right-click "Pause hibernation" for the tabs you want to keep open. Plus quiet performance wins under the hood.

Memory Pressure Tiers

The old "Smart Memory Pressure" toggle was a single switch. Now it's four tiers (Off, Conservative, Balanced, Aggressive) so you can pick exactly how aggressively Tab Hibernator reacts when your system RAM gets tight. Balanced is the new default.

Per-Domain Timeouts

Some sites deserve a longer leash. Under Settings → Exceptions, you can now set custom inactivity timeouts per domain. For example, give github.com 4 hours so your long-running PRs don't get put to sleep. Set a domain to 0 to never hibernate it, without using the whitelist.

Right-Click "Pause Hibernation"

Reading something you don't want to lose? Right-click any tab and choose Tab Hibernator → Pause for 15 min / 1 hour / until I close / never. A small ⏸ badge appears on the toolbar icon for that tab so you can see the pause is active.

Toolbar Tooltip Preview

Hover the extension icon and you'll see a live summary: total hibernated tabs, total memory freed, and the titles of the three most recently suspended tabs. Discover what was put to sleep without opening the popup.

Quieter Storage Writes

Tab activity, scroll position, and form-input events are now batched into a single chrome.storage write with a 150ms debounce. The result is noticeably less background I/O churn when you have many tabs open, and it's a free performance win.

Direct Support via Razorpay

Tab Hibernator Pro is still free. The Support link in the popup, dashboard, and Settings → About now routes to Razorpay (UPI, cards, wallets), so no more bounced international payments. Every contribution keeps the extension free for everyone.
